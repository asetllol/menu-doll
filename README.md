# Menu Doll

A lightweight Fabric mod that displays your player model with your current skin in the Minecraft main menu and pause menu.

The model follows the direction of your cursor, giving the menu a more personal and dynamic look.

## ✨ Features

* 🧍 Displays your player model using your current Minecraft skin
* 🖱️ The model looks towards your cursor
* 🏠 Supports the main menu
* ⏸️ Supports the in-game pause menu
* ⚙️ Configurable appearance and position
* 👤 Optional username display
* 🎨 Adjustable model size
* ↔️ Adjustable X and Y position
* 🌓 Optional username background
* 🌍 Multiple language translations
* 🪶 Lightweight and purely visual — does not affect gameplay

## ⚙️ Configuration

Menu Doll provides an in-game configuration screen where you can customize the model separately for the main menu and pause menu.

Available options include:

| Option                  | Description                                              |
| ----------------------- | -------------------------------------------------------- |
| **Show Model**          | Enable or disable the player model                       |
| **Show Username**       | Display your Minecraft username                          |
| **Size**                | Change the model size                                    |
| **X Offset**            | Move the model horizontally                              |
| **Y Offset**            | Move the model vertically                                |
| **Username Background** | Toggle the background behind the username                |
| **Position**            | Place the model to the left or right of the menu buttons |
| **Reset All**           | Restore the default configuration                        |

## 📦 Installation

### Requirements

* Minecraft
* Fabric Loader
* Fabric API
* Mod Menu
* Menu Doll

Download the latest `.jar` file from the **Releases** section of this repository.

Place the downloaded `.jar` file into your Minecraft `mods` folder.

Then launch Minecraft using your Fabric profile.

## 🛠️ Building from Source

Clone the repository:

```bash
git clone https://github.com/asetllol/menu-doll.git
cd menu-doll
```

Build the mod with Gradle:

### Windows

```powershell
.\gradlew.bat build
```

### Linux / macOS

```bash
./gradlew build
```

The compiled `.jar` files will be available in:

```text
build/libs/
```
